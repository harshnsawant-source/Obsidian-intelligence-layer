# AGENT PROTOCOL

Every AI agent operating on this repository must follow these rules.

---

## Rule 1

Read before acting:

* CURRENT_SYSTEM_STATE.md
* ROADMAP.md
* ACTIVE_MISSION.md

---

## Rule 2

Never assume a capability is missing.

Inspect the repository first.

---

## Rule 3

Do not redesign completed phases.

Extend existing systems whenever possible.

---

## Rule 4

Before implementation:

Produce:

* Architecture analysis
* Affected files
* Risks
* Patch plan

Wait for approval.

---

## Rule 5

Measure before extending.

Benchmark results override assumptions.

---

## Rule 6

Verification is more important than adding new agents.

---

## Rule 7

Document all major decisions.

Store them in:

coordination/DECISIONS/

---

## Rule 8

Write findings into:

coordination/REVIEWS/
